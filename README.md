# MiniDB — мини-СУБД на Python

Учебный проект для лабораторной работы №1.

## Описание

MiniDB — собственная мини-СУБД на Python с файловым хранением данных.

## Основные возможности

- Создание таблиц и описание их структуры.
- Поддержка типов данных `INT`, `STRING`, `FLOAT`.
- Проверка уникальности первичных ключей.
- Проверка внешних ключей.
- Добавление, просмотр, изменение и удаление записей.
- Поиск записей по условиям.
- Использование условий `AND` и `OR`.
- Сохранение данных между запусками программы.
- Консольное меню для работы с базой данных.
- Автоматические тесты для проверки работы системы.

## Структура базы данных

База данных состоит из трёх таблиц.

### 1. Таблица `datasets`

Хранит информацию о наборах данных.

| Поле | Тип | Описание |
|---|---|---|
| `id` | INT | Уникальный идентификатор |
| `name` | STRING | Название набора данных |
| `task` | STRING | Тип задачи |
| `size` | INT | Размер набора данных |

### 2. Таблица `models`

Хранит информацию о моделях.

| Поле | Тип | Описание |
|---|---|---|
| `id` | INT | Уникальный идентификатор |
| `name` | STRING | Название модели |
| `version` | STRING | Версия модели |

### 3. Таблица `experiments`

Хранит информацию об экспериментах.

| Поле | Тип | Описание |
|---|---|---|
| `id` | INT | Уникальный идентификатор |
| `dataset_id` | INT | Идентификатор набора данных |
| `model_id` | INT | Идентификатор модели |
| `accuracy` | FLOAT | Точность модели |
| `status` | STRING | Статус эксперимента |

Таблица `experiments` связана с двумя другими таблицами:

- `dataset_id` ссылается на `datasets.id`.
- `model_id` ссылается на `models.id`.

Система проверяет, существуют ли связанные записи, и не позволяет добавлять некорректные ссылки.

## Файлы проекта

- `main.py` — создание и настройка таблиц.
- `schema.py` — описание структуры таблиц.
- `storage.py` — хранение данных и основные операции с ними.
- `cli.py` — консольное меню.
- `seed_data.py` — заполнение базы тестовыми данными.
- `test_minidb.py` — автоматические тесты.
- `data/` — файлы с данными и схемами таблиц.

## Как запустить проект

Для работы необходим Python 3.

Запуск основной программы:

```bash
python main.py
```

Запуск консольного меню, если оно запускается отдельно:

```bash
python cli.py
```

Заполнение базы тестовыми данными:

```bash
python seed_data.py
```

Запуск автоматических тестов:

```bash
python -m unittest test_minidb.py
```

## Хранение данных

Данные таблиц хранятся в CSV-файлах, а структура таблиц сохраняется отдельно в файлах схем.

Благодаря этому данные не исчезают после завершения программы и остаются доступными при следующем запуске.

## Проверка работы

Автоматические тесты проверяют основные возможности системы:

- создание таблиц;
- уникальность первичных ключей;
- проверку внешних ключей;
- поиск и фильтрацию записей;
- изменение и удаление записей;
- сохранение данных после повторного открытия базы.

## Вывод

В результате работы создана простая файловая мини-СУБД на Python. Она поддерживает основные операции с данными, проверяет связи между таблицами и сохраняет информацию между запусками программы.
