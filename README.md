# MiniDB — файловая мини-СУБД

Учебный проект для лабораторной работы №1.

## Описание

MiniDB — собственная мини-СУБД на Python с файловым хранением данных. Проект разрабатывается поэтапно без использования готовых СУБД и ORM.

## Текущие возможности

- Создание трёх таблиц: `datasets`, `models`, `experiments`.
- Сохранение схем таблиц в собственном текстовом формате.
- Сохранение записей в CSV-файлах.
- Поддержка типов `INT`, `STRING`, `FLOAT`.
- Проверка типов данных перед вставкой.

## Запуск

Требуется Python 3.

```bash
python3 main.py
```

## Структура проекта

- `main.py` — запуск и демонстрация.
- `storage.py` — файловое хранение.
- `schema.py` — схемы таблиц и проверка типов.
- `data/` — файлы базы данных.
